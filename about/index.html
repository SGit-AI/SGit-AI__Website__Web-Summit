About this site

Who

One human operator, Dinis Cruz, and an AI agent (Claude Code) that writes and releases the site. The agent has a public identity: see the agent.

The people, the agent and the roles still open are on the team page.

How it is built

Pages are written as markdown in content/ and rendered by node admin/build/build.mjs, which also writes the sitemap, llms.txt and the markdown twin of every article. The generated HTML is committed, because GitHub Pages serves the repository as it is. Nobody edits a generated page by hand.

How it is released

Push toTagMeaning
devv0.1.x, next minora release; the site goes live
mainnext major, v0.N.0a deliberate promotion

CI runs three jobs in order: validate, tag, deploy. A red validate means no tag and no deploy. The version lives in admin/build/version.txt, appears in every page's footer, and is in the subject of the release commit (site v0.1.2: one sentence). The article on how this site is set up explains each step.
