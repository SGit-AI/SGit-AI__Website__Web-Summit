The agents, and the prompts to start them

How to start each agent: open a new Claude session in the right account, paste its prompt, let it run once, then create a scheduled task that fires into that same session on the schedule given (a fresh session per run loses the clone and the state). One session per scheduled agent (level 6 on the start page).
