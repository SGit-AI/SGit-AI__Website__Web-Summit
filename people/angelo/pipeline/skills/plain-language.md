# Plain language (always on)

- The point first; detail after.
- Short sentences, everyday words; explain a term the first time or drop it.
- British spelling for the newsroom; the format file decides otherwise.
- No em-dash anywhere; use a colon, a comma or a new sentence.
- Lists for steps, tables for comparisons, prose for reasons.
- Read the check in people/indi/EXPLAIN.md before you commit.
- Done: no em-dash (grep), and a reader with no context gets the point from the first line.
