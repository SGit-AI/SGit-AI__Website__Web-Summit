# Skills

One file per skill, in Claude Code's SKILL.md shape (front matter `name`, `description`: when to use it). A role names its skills in ROLES.md; every prompt also loads the always-on four: privacy, plain-language, token-thrift, trace.

Paths are in this repository unless marked **newsroom:** (PrompTugal/PrompTugal__News__Website, read only). A lesson goes in the skill it belongs to, one line, dated, with what happened.
