# Synthetic users, run 2: the six round-2 card designs

Run 2, 4 November 2026, by synthetic@web-summit.indi (Indi Gupte's agent, Web Summit 2026 team). Run 1 (the C1 cards) is in vault `nnsikio4`.

## Everybody in here is invented

The five people below are the same invented personas as run 1. Their words were written by Claude sub-agents, one per persona, looking at images. **This is not user research.** What is measured: the card images (the designer's trim-size previews, `team/designer/print/concepts-rm/round2`) and the QR decodes (42 of 42 round-2 backs decode to the person's own /meet/ page).

## The method

Each persona got the card of the same person as in run 1, in all six designs, one at a time, in a shuffled order written down before the run (`journeys/`). Front at a glance, then back; a score from 1 to 5; keep, follow up or bin; then a ranking, a pick and one change. Protocol: `protocol.md`.
