## Risk analysis
Inferences from the card, not facts about Cisco. A person must check each.
- Agents built on a shared developer platform may be given more access than their task needs.
- Open-source agent projects spread. Each adopter inherits the defaults.
- When many agents work together, it is unclear who is answerable for an action.

## How RiskMandate helps
- Reach: list what each agent built on DevNet can contact.
- Mandate: state the task its owner approved.
- Gap: the connections the agent has but never needs.
- Barriers and Provenance: name the controls and the owner.
- A possible hook: open projects ship an example behaviour policy, so every adopter starts with a stated mandate. This is a suggestion, not something Cisco has said.
