## How it works

1. The agent drafts a post in `posts/<date>-<slug>.md`: format, media (by vault id and path, never a file in git), caption, hashtags, alt text, first comment, sources, when to post, status.
2. Silvio reads it, changes what he wants, and says yes in the session. The status becomes "approved by Silvio" with the time.
3. Silvio downloads the media from the vault `ws-team-videos` (h9in5em4), posts it, and gives the agent the post's URL. The status becomes "posted".
4. Comments and messages: Silvio pastes them into the session; the agent drafts one reply each; Silvio posts them. They never go into this repository.
