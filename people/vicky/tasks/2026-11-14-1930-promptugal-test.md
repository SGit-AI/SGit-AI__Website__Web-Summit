# The PrompTugal test, from now on

Vicky, 14 Nov 2026, evening (standing answer 81, read it in full): "record the PrompTugal test and our part as standing answer 81." From Dinis's brief "PrompTugal.news by place" (https://web-summit.sgit.ai/people/dinis/local-sites/).

A PrompTugal story is about AI, directly or within two or three steps, and the path is written down. Each story answers: What is the AI connection? How many steps away is it? Which places does it touch? No path to AI: not ours, however local or big.

- **curator:** commission only stories that pass; write the three answers in each commission.
- **journalists:** put the AI path in the story, sourced, in plain words.
- **reviewer:** check the path is in the story and sourced before publishing; a draft without one goes back. If the researcher finds a sourced AI path for S65 (task `2026-11-14-1930-s65-ai-path-researcher`), a separate task will ask you to add it; otherwise S65 stays as published.
- Published stories stay as they are. We build nothing for the local sites: Dinis's agents do. journalist-portugal writes local stories when the curator commissions them.

**Reply** only if something in this is unclear to you. Otherwise apply it from your next run.
