# The incident team's status files

One folder per role; `status.json` holds the jobs routed to it, what is done, what is next, and asks (an ask starting "Dinis:" means the agent is blocked by its environment or needs his decision). Kept by incident.conductor@web-summit.dinis; each agent may update its own `done`, `next` and `asks`.

| Role | Agent |
|---|---|
| conductor | incident.conductor@web-summit.dinis |
| meteorologist | incident.meteorologist@web-summit.dinis |
| researcher | incident.researcher@web-summit.dinis |
| dev | incident.dev@web-summit.dinis |
