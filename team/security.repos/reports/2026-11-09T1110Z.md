### LOW

1. **A company's general address stays in PrompTugal's public git history.** PrompTugal/PrompTugal__News__Website, commits `e7e97428` (8 Nov 20:06) and `533cb0eb`: `board/team/security/findings.md` and `board/team/security/reviews/2026-11-08-2005-catch-up.md`.
   - **What:** security@PrompTugal.dinis quoted a company's general contact address (a company address, not a person's) while reporting it. It removed the address from the files in `dd7f544b` (9 Nov 06:09, its S21), so it is no longer on `dev`'s tree, but it stays in the history of a public repository.
   - **Why it matters:** the comms protocol keeps every address out of PrompTugal's repository. A company's published general address is low risk, but quoting a finding's value spreads it.
   - **Owner:** security@PrompTugal.dinis. Name the file and the kind, not the value. Rewriting history is not asked for, and is not allowed here.
2. **The event app's privacy manifest changed twice in the window; App Store Connect's privacy answers should match the build under review.** PrompTugal/PrompTugal__App__iOS: `d2318d9` (8 Nov 11:33) added a collected data type ("other user content") to `Apps/PrompTugal/Resources/PrivacyInfo.xcprivacy`. Later commits removed Ask (which sent user text to openrouter.ai), the vault and dictation from the public app (`eeab533`, 23:27), and dropped the `webcredentials:promptugal.news` associated domain (`9d35705`, 23:31).
   - **Where it ends:** on `dev`, `NSPrivacyCollectedDataTypes` is empty. The camera, Face ID, microphone and speech purpose strings are gone, and the vault background task is gone.
   - **Network:** the hosts the app calls are unchanged. PTSync, newly linked, fetches only promptugal.news. The new transport and parish addresses in `Shell/NowView.swift:388-392`, and `tel:112`, are links the user taps, not requests.
   - **The line:** this is within content/apps.md, because the surface shrank and each commit said so.
   - **Risk:** the build already submitted to Apple may declare more than the next one, or the reverse.
   - **Owner:** the iOS app's release agent (the `split/testflight` lane) and Dinis. Before the next submission, check App Store Connect's privacy answers against the build being sent.
3. **The public site can call two commands in Angelo's desktop app.** SGit-AI/SGit-AI__Website__Web-Summit, `people/angelo/app/desktop/src-tauri/capabilities/live-page.json` (from `491c45e8`, 8 Nov, and onwards), with `tauri.conf.json` `"csp": null`.
   - **What:** any page under `https://web-summit.sgit.ai/*` may call the app's two commands (`show_menu`, `app_action`).
   - **Why the risk is low:** the commands take fixed ids only. The URLs they open are constants in `src/main.rs`. There is no shell, file or network permission.
   - **Why it is worth narrowing:** everyone on the team can publish to that site, so a careless or injected page reaches those commands.
   - **Suggestion:** narrow `remote.urls` to `https://web-summit.sgit.ai/people/angelo/app/*` and set a CSP.
   - **Owner:** dev.app@PrompTugal.angelo.
4. **Shared build code edited from person lanes.** SGit-AI/SGit-AI__Website__Web-Summit, `admin/build/build.mjs`.
   - **What:** dashboard@web-summit.vicky edited it in four commits on `dev` (the compact dashboard, 8 Nov). The same change is on `workers/dev.app`, from dev.app@PrompTugal.angelo.
   - **Assessment:** the change is benign. It renders `:::details` blocks as native `<details>` and adds no script. But `admin/build/` runs in CI with `contents: write` and `pages: write`.
   - **Owner:** conductor@web-summit.dinis, to confirm that this lane may edit shared build code. Not a request to revert.
5. **One access token for the whole team.** Recorded by the conductor at Dinis's word in `team/conductor/notes/2026-11-09-dinis-decisions-1055.md` (`3bfbc8c7`), item 1: the team's access token will be posted in the team's WhatsApp group.
   - **Assessment:** this is Dinis's decision and outside the repositories, so I report it and do not block it. One shared token means no one person's agents can be cut off alone, and any session holding it can act as all of them.
   - **Suggestion:** give the token an expiry, or plan to rotate it after the event. No agent should commit it or echo it to a transcript.
   - **Owner:** Dinis.
