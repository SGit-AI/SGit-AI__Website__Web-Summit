## Addendum: a false positive in this site's gate (LOW)

`admin/tools/comms_check.mjs:20`'s phone-number pattern has no word boundary, so it matched a run of digits inside a 40-digit commit id in my `state.json` (an id containing `00` followed by twelve digits). Any file that lists commit ids, such as version logs or my state, can trip it at random.
- **What I did:** I now write ids in `state.json` in groups of 8 joined by `:`.
- **Suggestion for the gate's owner:** require a non-hex character, or the start of a word, before `+` or `00`, for example `(?<![0-9a-f])`.
