## Findings

### MEDIUM

1. **The event app now reads videos from an SGit vault, at whatever https server the downloaded list names.**
   - **Where:** PrompTugal/PrompTugal__App__iOS `6c8ccd0` (conductor-newsapp@web-summit.indi, 15:17, at Indi's word), on `dev`.
     - News gains a Videos form.
     - `Packages/PTNews` now depends on `SGitVault`, and the public app's project gains the `SGitVault` package reference. On 8 November that code was removed from the public app ("PTAsk, PTVaultUI and SGitVault are Team-app only", `eeab533`).
     - `Packages/PTNews/Sources/PTNews/Videos.swift` reads `https://promptugal.news/api/v1/live/videos.json`, opens each video's vault with the key in that list, and fetches the poster as the list shows. On a tap it downloads and decrypts the manifest, `init.mp4` and the segments, joins them into one MP4 in Caches, and plays it.
   - **Stated, as content/apps.md requires:** the commit says "new network reads from dev.send.sgraph.ai … in the public app; decrypted video kept in Caches", `For: security.repos@`.
   - **No change to permissions, entitlements or the privacy manifest:** `SGitVault` imports only Foundation, CryptoKit, CommonCrypto, Compression and Observation (no Keychain, no LocalAuthentication), so no purpose string is needed. No user data is sent. Path names with `/`, `\` or `..` are refused.
   - **What makes it MEDIUM** (the event app's line is "the smallest surface"):
     - **(a) The host is not pinned.** `VideoRules.server` (line 77) accepts any `https` URL with a host. The vault server and key come from `videos.json`, so whoever can change that file (any agent on PrompTugal.news, or anyone who compromises it) chooses which server every installed event app contacts, and what the app decrypts and hands to AVKit.
     - **(b) The key's form is not checked in the app.** The commit relies on the site's gate to allow only public read keys. The app parses whatever `read_key` arrives (line 159).
     - **(c) No size limit** on the manifest, the segments or the joined file, which is written to Caches.
     - **(d) The host is a `dev.` server** (`dev.send.sgraph.ai`) behind an App Store build. Its availability and logging are now part of the event app.
   - **Suggestions:**
     - Pin the endpoint to an allowlist (the vault host or hosts the team runs) in the app.
     - Accept only a public read key's form in the app, not only at the site's gate.
     - Cap the segment count and total bytes.
     - Load posters only when the Videos form is opened. It loads on the list today; keep that.
     - Decide whether App Review's notes should mention the vault reads.
   - **Owners:** conductor-newsapp@web-summit.indi and conductor@ios.PrompTugal.dinis. The release lane (devops.ios@) should check this before the next submission. Because of run 9's HIGH, this code is already going to TestFlight from `dev`.
