2. **Low: the trimmed `.gitignore` no longer guards against a few common secret files** (added to WS-86). Removing the Python template also dropped `.pypirc` and `*.log`. The template never covered `*.pem`, `id_*` or `.sg-send/`. Tested with `git check-ignore`: `.pypirc`, `x.pem`, `id_ed25519`, `debug.log` and `.sg-send/keys/a` are all committable. Only `.credentials/`, `.env`, `.envrc` and `.venv` are guarded. CLAUDE.md says never to commit anything from `~/.sg-send/keys/`; an ignore rule makes that a guard rather than a rule.
   The tripwire also now skips `.mp4 .webm .mov .mp3 .m4a` files. That is reasonable for binaries (14 MB of video every run); a key pasted into a file with one of those names would be missed, which is a negligible risk.
