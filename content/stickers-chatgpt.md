**How to use it** (Dinis, 4 November): open ChatGPT (or any image model), paste **the first message**, then paste **one sticker at a time** and ask for four variations. Every sticker block below is complete on its own, so you can copy any one. Save the best of each and send them to the designer agent, which places the RiskMandate seal, sets long text in vector and makes the print files for ProntaPrint ([the creative set](../creative/index.html) has the reasons; [/stickers/](../index.html) has the corporate four).

**What the printer can do by Friday:** kiss-cut circles, squares and rectangles on white vinyl, so every design fills its shape; nothing is cut to an outline.

## The first message {#first}

```
You are helping RiskMandate design a set of funny laptop stickers for Web Summit Lisbon (9 to 12 November 2026). RiskMandate helps companies give their AI agents a mandate: know what an agent can reach, define what it is allowed to do, and control the gap between the two. The stickers are a collectible set called RiskMandate, Web Summit Edition: souvenirs of a road trip to Lisbon, each a two-second joke about agents with too much access. I will paste one sticker at a time. For each, make four variations, keep the words exactly as I give them, and if any letter is wrong, try again with the words larger and simpler. Never draw a company logo: where a logo goes, leave a plain circle.
```

## When a result is good {#next}

1. Save it as PNG at full size.
2. Note which sticker it is (its number).
3. Send it to the team (or drop it in the stickers vault); the designer agent turns it into a print file: CMYK, 3 mm bleed, the seal placed, text checked letter by letter.
