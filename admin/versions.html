Versions

Every push to dev is a minor release (v0.1.x); every push to main is a major one. CI tags the release.

v0.1.72026-10-28Brings the repository up to the sgit.ai checklist for a new repository (docs/guidance/repositories): participant disclosure, BRIEF-CORRECTIONS.md and REALITY.md, a markdown twin for every page, and three more gate checks (twins and llms.txt, orphan pages, private sgit key shapes).
