PROMPTUGAL.NEWS - BRAND IDENTITY AND GUIDELINES v2.0
5 November 2026

Selected identity
Write PrompTugal.news with uppercase P and T. On paper, Promp is ink, T is red,
ugal is green, and the dot and italic news are ink black (#121317).
The selected square stamp uses PT above .news, a thin frame and a green rule.
Both initials remain visible in the responsive favicon.

Light and dark
Use light assets on light backgrounds. On dark backgrounds, use the dark assets
with paper-coloured neutral text and dot, red #F07278 and green #6DBB7E.
Monochrome stamp and wordmark masters are also included.

Contents
Promptugal-Brand-Guide.pdf - ten-page identity and guidelines document.
presentation/ - updated illustrative brand presentation, used on page 2.
logos/ - outlined wordmarks and framed mastheads in SVG and transparent PNG.
icons/ - selected PT.news stamps plus light and dark favicon subfolders.
Each favicon folder has ICO with 16/32/48/64/128/256px frames, SVG and PNGs.
Apple touch icon (180px) and 192/512px app icons use the full square stamp.
templates/ - editable social-card and presentation-title SVG templates.
fonts/ - original Newsreader and IBM Plex fonts with their OFL licences.
implementation/ - CSS colour tokens and local font loading.

Type
Wordmark - Newsreader 600, optical size 72. Italic suffix - Newsreader 400 at 78%.
Favicon - a heavier, small-optical-size Newsreader cut, exported as paths.
UI - IBM Plex Sans 400/600. Metadata - IBM Plex Mono 400.
All logo and icon SVGs are outlined and require no installed fonts.
Template copy is editable and uses the included font families.

Colour / sRGB
Paper #F6F3EC. Ink #121317. Red #C52830. Green #006600.
Dark accents #F07278 and #6DBB7E. Use the dot in the neutral text colour.
Print conversions should use the printer's ICC profile and a physical proof.

Sizes and space
Wordmark - starting minimum 240 CSS px / 45 mm. Clear space is half a capital P.
Square stamp - starting minimum 96 CSS px / 20 mm. Clear space is 1/8 side length.
Favicon - use the dedicated PT and dot artwork at small browser sizes.
