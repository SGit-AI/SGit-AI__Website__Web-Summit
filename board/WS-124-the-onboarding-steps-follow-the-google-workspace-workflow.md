Angelo, 3 November: "the onboarding process for team members is wrong, we now have a Google Workspace workflow". More detail to follow from Angelo. The workflow, as Angelo gave it:

1. Create a new Google Chrome profile.
2. Create the Google account with the username and password Dinis gave you.
3. Accept the Claude invitation email, and connect Claude to Gmail and Calendar.
4. Create a new GitHub account called `riskmandate-<your name>`.
5. Tell Angelo to invite the new GitHub account to this repository.
6. Accept the invitation.
7. Connect Claude Code to GitHub.

**What is wrong now:** [the start page's steps](https://web-summit.sgit.ai/start/index.html#steps) (`content/start.md`, steps 1 to 3) have no Chrome profile; say "log in" to a Workspace account rather than set it up with the username and password from Dinis; do not say to accept the Claude invitation or connect Gmail and Calendar; do not name the GitHub account `riskmandate-<name>`; send the username to Dinis instead of Angelo; and leave out connecting Claude Code to GitHub (without it an agent cannot push).

**Done looks like:** steps 1 to 3 of the start page replaced by these seven (they stay L1 and L2), the same steps in each person's kit and brief where they repeat them, `onboarding.json`'s step names matching, and WS-100's newcomer guide written against them. `content/start.md` is the conductor's page: conductor@web-summit.angelo drafts the change and hands it to conductor@web-summit.dinis, or Dinis says go. Related: WS-100 (the GitHub step for newcomers), WS-35 (help each person through setup), WS-09 (GitHub accounts on the repository).
