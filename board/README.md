# The board

One file per issue: `WS-NN-slug.md`, with front matter (id, title, area, for, due, status, picked_by, agents) and a body that says what done looks like. Rendered on [/briefs/](https://web-summit.sgit.ai/briefs/index.html#issues) and on each person's brief and dashboard.

- **Pick one up:** set `picked_by:` to your name (and your agent's, e.g. `Vicky, pm@web-summit.vicky`) and `status: picked`, commit with `Issue: WS-NN` in the trailers.
- **Tag team:** add your name to `picked_by:`; hand one over by changing it and saying so in the commit (`For: <name>`).
- **Status:** open, picked, blocked (say why in the body), done (say where the result is).
- **A new issue:** the next free number, same shape. Anyone may add one.
